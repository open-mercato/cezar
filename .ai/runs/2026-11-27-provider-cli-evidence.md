# Agent provider launch evidence

Verified on 2026-11-27 for [spec PR #2548](https://github.com/open-mercato/cezar/pull/2548). CLI checks used fresh temporary homes, working directories, caches and environments. The only credentials supplied were synthetic. The loopback HTTP fixture recorded the path, bearer and model and returned HTTP 400. It performed no inference. No vendor login, real credential store, personal configuration or paid turn was used.

## Integration and reproduction

- Run `vitest run packages/cezar/src/core/agent-auth-methods.test.ts` from the repository root. The tests exercise every listed method using synthetic options and check credential removal, model namespaces, registration and the OAuth acknowledgement.
- Call the mapping only for explicit selections. Strip inherited environment names case-insensitively before applying the launch environment. A recorded provider choice needs the original method and remote model ID so that Continue can create new launch-only overrides.
- Pass gateway model IDs through verbatim, including slashes. When the caller resolves an automatic gateway model, select an actual ID from the method's fetched catalog. Pi and OMP registration requires numeric context, output and pricing metadata. The adapter uses 32K context, 4K output and no price estimate. These values do not establish the model's actual limits or cost.
- Verify native subscriptions against the effective vendor account and model. A CLI installation, a nonempty catalog or an aggregate connected flag can also describe API-key auth. Settings, policy conflicts and revoked vendor credentials can prevent a verified mechanism from working on a particular host.

The final mapping was exercised directly against all five applicable CLI binaries (Pi, OMP, OpenCode 1.x and 2.x, and Kimi). Each custom launch sent exactly the selected fake bearer and the raw slash-qualified model to the loopback endpoint. Both Pi-family CLIs also loaded the extension as compiled ESM JavaScript. The 27 module tests and 102 related environment, Pi runner and model identity tests passed. Removing the OMP effective-source check made the negative subscription test fail.
