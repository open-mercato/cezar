## Regression evidence

Run node packages/desktop/scripts/test-rustls-security.mjs with Cargo and a C compiler available. The runner reads the actual desktop Cargo.lock version, creates an isolated manifest, and builds that exact crate. It performs real in-memory TLS1.2/1.3 handshakes and encrypted data transfer, captures session Debug through the public ClientSessionStore seam, verifies resumption, and rejects a mismatched server certificate before data delivery.

With only Cargo.lock stashed, Rustls0.23.45 fails the TLS1.2 master-secret and TLS1.3 resumption-PSK redaction checks. Both data/resumption controls and the certificate-rejection control still pass. Restoring the generated0.23.46 lock gives5/5. The test never prints secret-bearing Debug values, including on assertion failures. Scratch manifests/targets are removed on exit unless an explicit shared CARGO_TARGET_DIR is supplied.

Host: Linux x86_64, Rust1.100.0. This host initially lacked Cargo and a C compiler; Rust minimal tooling was installed without modifying the shell profile and a checksum-verified temporary Zig compiler supplied the test linker. Local command:

```sh
CARGO=/home/maintenance/.cargo/bin/cargo CC=/tmp/cezar-8aab217b-cc AR=/tmp/cezar-8aab217b-ar CARGO_TARGET_X86_64_UNKNOWN_LINUX_GNU_LINKER=/tmp/cezar-8aab217b-cc CARGO_TARGET_DIR=/tmp/cezar-8aab217b-rustls-target timeout 360 node packages/desktop/scripts/test-rustls-security.mjs
```
