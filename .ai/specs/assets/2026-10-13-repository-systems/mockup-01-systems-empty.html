Systems

Systems tell agents how your repositories depend on each other — who provides an API, who consumes it, where the contract lives.

No systems yet

Without a system every project works exactly as today. Create one when several registered repositories form one application (a web app and its API, or a set of services).

Suggested from tags shared by two or more projects
storefront3 projects — web, api, payments-sdk
ops2 projects — infra, worker

Tags stay filters only. Creating a system copies the tagged projects in as members; you then add roles and links.
