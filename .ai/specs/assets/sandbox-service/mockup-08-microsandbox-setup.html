What the other tabs say
Linux
Needs KVM. cezar checks /dev/kvm. If it is missing, enable virtualization in the BIOS. If it is not readable, run sudo usermod -aG kvm $USER and log in again. Then curl -fsSL https://install.microsandbox.dev | sh.
Windows
Needs Windows Hypervisor Platform: Enable-WindowsOptionalFeature -Online -FeatureName HypervisorPlatform, then reboot and install.
macOS · Intel
Not supported by microsandbox. Use an SSH host running Linux with KVM, or Daytona. Both are in "Add account".
Inside a VM or container
Nested virtualization must be on. Otherwise, use an SSH host.
