# OpenCode V1 + V2 compatibility

## Goal and constraints

Keep the zero-config V1 runner working and support the installed V2 2.0.19 CLI.
Do not change the public AgentRunner/AgentSession or normalized event contracts,
add dependencies, change the shared OpenCode service, or require user configuration.

## Design

- Spawn a private loopback `opencode serve` per session as before. Give that child
  a random in-memory password in both `OPENCODE_SERVER_PASSWORD` and V2's
  higher-precedence `OPENCODE_PASSWORD` and send Basic authentication on
  both HTTP and SSE (supported by both versions). Never log credentials.
- Probe `GET /api/info` with a bounded request. A V2 version selects V2; a V1
  missing/non-JSON endpoint selects V1. Authentication and transport failures
  must not masquerade as V1.
- V1 retains `/session`, `/event`, message parts and its turn-idle grace policy.
- V2 uses `/api/session` with an explicit worktree location, model reference and
  autonomous session permissions; unwrap `{data}`. Prompts contain `text` and
  use `/prompt`; interruption uses `/interrupt`.
- V2 prompt acknowledgement is NOT turn completion. Wait for its agent loop via
  `/api/experimental/session/:id/wait` while consuming native SSE events. Use
  the existing bounded idle grace only AFTER the wait settles. Server exit,
   stream loss, cancellation and the run deadline remain exits.
   A dropped V2 wait never arms completion grace: only native idle or a terminal
   failure/deadline may close that path. V1's live-session drop policy is unchanged.
- A session-local adapter converts native `{type,data}` text/reasoning/tool/
  usage/error/idle events into the existing mapper input. Ignore unrelated
  sessions, unknown events and malformed input. Preserve stable item identities.
- Accept both the V1 credential summaries and V2 stored/environment credential
  rows; keep ambiguous output unknown, never optimistically connected.

## Implementation and verification plan

1. Add authentication regression cases for V2 stored/environment credentials,
   empty and malformed output; confirm red, implement, retain V1 cases.
2. Add native V2 event adapter tests using the released 2.0.19 client contract;
   cover deltas, final snapshots, tool lifecycle, usage and foreign-session filtering.
3. Add a strict V2 mock server enforcing auth, location, model, permissions,
   request shapes and asynchronous acknowledgement. Test one-shot, multi-turn,
   delayed work, failure, cancellation and stream loss; confirm red.
4. Wire protocol selection and authenticated HTTP/SSE without changing V1.
5. Run targeted tests, typecheck, full Vitest and node unit suites; inspect diff.
   Validate private V2 API creation/subscription without invoking a paid model.
