Pair the Cezar app with this demo

This demo runs cezar with a mock agent: nothing on it is real work. Pairing connects the app through the Cezar relay, the way a phone pairs with a cezar on a laptop.

  1. Press Show a code below.
  2. In the Cezar app, choose Enter code and type the code. Codes last two minutes and work once.
  3. When the app shows a number, check that this page shows the same number, then press Approve.
