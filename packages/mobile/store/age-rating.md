# Age rating answers

The app is a developer tool. It shows the cockpit of a cezar the user runs: tasks, code, diffs and the
Manager, an AI chat run by the user's own coding agents. Navigation is confined to the paired server's
origin; any other link opens in the system browser (`NavigationPolicy`). No purchases, ads, gambling,
location sharing or contact with strangers.

## Google Play: IARC questionnaire

Play Console > **Policy and programs > App content > Content rating**. Category: **All other app
types** (utility, productivity, communication or other; not a game).

| Question | Answer |
| --- | --- |
| Violence, fear, sexuality, nudity, crude humour, profanity | No |
| Controlled substances (drugs, alcohol, tobacco) | No |
| Gambling, simulated gambling, real-money contests | No |
| Does the app allow users to interact or exchange content with other users? | **No.** The app connects a user to their own cezar. It has no chat with, or sharing to, other people. Pull request and issue text from a forge is read-only material for the user's own work |
| Does the app share the user's current physical location with other users? | No |
| Does the app allow users to purchase digital goods? | No |
| Is the app a web browser or search engine? | **No.** It loads only the paired cezar's own pages |
| Does the app contain AI-generated content? (if asked) | The Manager shows text written by the user's own coding agents about their code. Answer per the current form; it is not open-ended content generation for entertainment |
| Is this a news app? Is it targeted at children? | No / No |

Expected result: **Everyone / PEGI 3 / USK 0 / ClassInd L**.

Also under **App content**: Target audience **18 and over** (a developer tool; this keeps the app out of
the Families policy); News app **No**; Ads **No ads**; Government app **No**; Financial features
**None**; Health **None**.
