Save an API key for the repository, then select a Linear project or team. Only that scope appears in the issue view. Other Cezar projects do not inherit the credentials unless you save them with **Visible only for this project** unchecked and pick them under **Use a shared connection** in the other project.

## Where to find it

Settings → project → Issue tracker

## How to use it

1. Choose Configure Linear credentials and save the API key.
2. Open Browse Linear.
3. Find and select a project or team, then click Connect.

> **Good to know**: Changing credentials requires selecting the scope again. Removing the local connection does not revoke the token at the provider.
