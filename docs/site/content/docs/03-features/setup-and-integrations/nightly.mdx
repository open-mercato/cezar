Nightly includes merged changes. To test a specific pull request, use its assigned preview version.

## Where to find it

Terminal → `npx cezar-cli@nightly`

## How to use it

1. Choose nightly to test merged changes.
2. When testing a pull request, use its exact preview version.

> **Good to know**: A test release may differ from the stable version. Include the exact package version when reporting a bug.
