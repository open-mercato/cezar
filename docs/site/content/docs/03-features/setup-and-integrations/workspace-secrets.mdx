Global Secrets stores values for the workspace. A project can override a shared secret by saving its own value under the same name.

## Where to find it

Settings → Global → Secrets

## How to use it

1. Add a name and value in global Secrets.
2. Select the allowed readers and save.
3. If one project needs a different value, add a secret with the same name in that project's settings.

> **Good to know**: Only check steps or Cezar itself can read these secrets. Agent sessions cannot access them. Deleting an entry does not revoke the key at its provider.
