The editor shows a command corresponding to the automation configuration. Copy as CLI is also available in the rule menu.

## Where to find it

Automations → editor → Copy as CLI

## How to use it

1. Configure or open a rule.
2. Copy the generated command.
3. Before using it, check the project and connections in the destination environment.

> **Good to know**: Copying the command does not run the automation.
