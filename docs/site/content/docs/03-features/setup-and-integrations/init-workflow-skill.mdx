`cezar init` creates an example workflow and skill in `.ai/cezar/`. Run it in the repository, then adapt the saved instructions and workflow to your project.

## Where to find it

Repository terminal → `cezar init`

## How to use it

1. Open a terminal in the repository.
2. Run `cezar init`.
3. Adapt the example workflow and skill in `.ai/cezar/`.

> **Good to know**: Initialization is optional. Cezar also works without manually prepared configuration.
