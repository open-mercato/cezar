Select a project connection, the events to watch, and the interval between checks. For status changes, specify the destination states. For label additions or removals, select the relevant labels.

## Where to find it

Automations → New automation → When Jira / Linear changes

Before the first automation exists, the Automations page explains what an automation is and offers the three triggers as tiles; the When an issue moves tile opens this form directly. How it works in the page header shows the same explanation in pictures at any time.

## How to use it

1. Connect the tracker in project settings first.
2. Select events and the required states or labels.
3. Describe the task, choose its agent, save, and enable the rule.

> **Good to know**: Available events depend on the connected provider. Once enabled, the rule tracks new changes; earlier matches do not create tasks.
