The mobile app connects to a cezar you host and shows that server's own cockpit, starting on Manager. It keeps your login in the phone's secure storage and can hold several servers. It is not in any store yet, so you build it yourself. Agents never run on the phone.

## Where to find it

`packages/mobile` in the cezar repository. The README there has the build steps.

## How to use it

1. Build the debug app and install it on your phone.
2. Enter your server's `https://` address.
3. If the server has a Basic login, enter the username and password. The app saves them only after the server accepts them.
4. The app reopens your last server on launch. The server list appears when that server cannot be reached. A link to it from inside the cockpit is still to come. **Forget** there deletes that server's password and website data from the phone.

The server must run in hosted mode. Links that leave your server open in the system browser.

## App lock

On Android, **Turn on app lock** on the server list asks for your fingerprint, face or screen lock each time the app starts and after a minute in the background. It is off by default and needs a screen lock on the phone. It only hides the app: anyone who knows the phone's screen lock can open it, and your login is stored the same way with the lock on or off. iOS has no app lock yet.

> **Good to know**: Plain `http://` is refused. Without a public server, reach cezar over HTTPS through ngrok, a Cloudflare Tunnel or `tailscale serve`. A temporary `trycloudflare.com` tunnel loads the cockpit, but live updates do not arrive through it. The Android debug build has been tested on an emulator. The iOS code has not been compiled yet.
