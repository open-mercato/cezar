Secrets stores encrypted values. The list shows their names and allowed readers, but does not reveal stored values. You can add, replace, or delete a secret.

## Where to find it

Settings → project → Secrets

## How to use it

1. Enter Name and Value.
2. Under Who may read it, select Check steps or cezar itself.
3. Choose Save secret. To replace a value, save it again under the same name.

> **Good to know**: Agent sessions do not receive secrets. Cezar stores the encryption key in the system keychain. When the keychain is unavailable, it uses a private file and indicates this in the panel.
