The `cezar run` command starts a task on the machine where you invoke it.

## Where to find it

Terminal → `cezar run`

## How to use it

1. Open the repository directory.
2. Enter `npx cezar-cli run` followed by the task text in quotation marks.
3. Review the result and changed files.

> **Good to know**: The selected agent's CLI must be installed and signed in.
