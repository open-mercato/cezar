cez runs list displays tasks from a running Cezar instance. --status filters by state, --all includes the archive, and --json returns data for further processing.

## Where to find it

Terminal → cez runs list

## How to use it

1. Set `CEZ_API_URL` to the running cockpit address.
2. Run cez runs list --status running,review.
3. Add --json for automated processing or --all to include archived tasks.

> **Good to know**: This command only reads data. `CEZ_PROJECT_ID` selects the project. Without it, Cezar uses the startup project.
