The details panel lets you select a workflow or skills, an agent, and additional instructions. If some source content cannot be transferred, the form identifies what is missing and lets you add context.

## Where to find it

Jira / Linear → issue → task panel

## How to use it

1. Open the issue and choose a workflow or skills.
2. Check warnings about omitted content and fill in Supplemental context if needed.
3. Add a Custom instruction and start the task.

> **Good to know**: You can also drag an issue row into the message field to prepare an agent task. This does not change the issue content in Jira or Linear.
