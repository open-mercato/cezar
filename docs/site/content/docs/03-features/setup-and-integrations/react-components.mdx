The specification describes @open-mercato/cezar-react, a package for embedding parts of Cezar in a React app. It would include a provider, components, and separate CSS. The reviewed commit has no `packages/react` directory, and the web cockpit remains a private SPA.

## Status

Specification: no package available to install

## What you can do today

1. Read the publishable-react-components specification.
2. For current integrations, use the exposed server API.

> **Good to know**: The library is a plan in the repository with no confirmed delivery date. The existing React app is not a published component library.
