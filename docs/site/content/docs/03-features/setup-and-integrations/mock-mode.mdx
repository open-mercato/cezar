The included mock agent returns simulated responses, allowing the demo to work without a network connection.

## Where to find it

`CEZ_DRY_RUN=1`

## How to use it

1. Start Cezar with dry-run enabled.
2. Create a sample task.
3. Follow the simulated run.

> **Good to know**: This mode is for demos and development. Responses are simulated and do not confirm that any code changes were made.
