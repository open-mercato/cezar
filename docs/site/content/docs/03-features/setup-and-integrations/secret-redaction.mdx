Redaction is enabled on the server by default.

## Where to find it

Enabled by default when saving task events and text

## How to use it

1. Leave redaction enabled.
2. Keep credentials out of commands.
3. Check logs before sharing them.

> **Good to know**: Redaction may miss unfamiliar formats, leaving them in the text. Set `CEZ_REDACT_SECRETS=0` to disable this feature.
