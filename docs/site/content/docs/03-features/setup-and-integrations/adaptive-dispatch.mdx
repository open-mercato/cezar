The planned controller would use host CPU and memory measurements. Under pressure, it would lower Dispatch concurrency, then restore the previous limit when the load drops.

## Status

Specification: not yet available

## What you can do today

1. Measure CPU and memory pressure on the host.
2. Temporarily reduce Dispatch concurrency and restore it after the load drops.

> **Good to know**: This feature depends on a separate Dispatch limit and resource-capacity measurements. The current semaphore uses fixed limits without an adaptive controller. There is no confirmed delivery date.
