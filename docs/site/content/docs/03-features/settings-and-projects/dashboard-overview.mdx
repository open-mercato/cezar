The dashboard combines project overviews, the queue, Needs you, and recent results. Each section links to the relevant tasks.

## Where to find it

Navigation → Dashboard → Overview

## How to use it

1. Open Overview.
2. Check Needs you and Queue & scheduling.
3. Select a project or result to open its tasks.

> **Good to know**: The dashboard reflects the available data sources. Missing data or a disconnected source does not mean there are no tasks.
