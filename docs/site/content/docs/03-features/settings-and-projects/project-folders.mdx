Default browse folder sets where folder browsing starts and the highest directory accessible in the picker. Default checkout folder sets the destination for Clone from GitHub and New project.

## Where to find it

Settings → Global → Projects

## How to use it

1. Set Default browse folder for Open local folder.
2. Set Default checkout folder for new projects.
3. Save and check the relevant add-project form.

> **Good to know**: Changing the checkout folder does not move registered projects.
