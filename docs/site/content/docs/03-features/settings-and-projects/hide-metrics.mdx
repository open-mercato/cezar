Set `CEZ_HIDE_TOKEN_USAGE=1` to hide token data, or `CEZ_HIDE_COST=1` to hide cockpit costs. The older `CEZ_HIDE_TOKEN_METRICS=1` flag hides both.

## Where to find it

Server environment variables

## How to use it

1. Set `CEZ_HIDE_TOKEN_USAGE=1` or `CEZ_HIDE_COST=1`.
2. Restart the server.
3. Check the view.

> **Good to know**: These settings affect presentation. They do not change billing or the usage data saved by the server and returned by the API.
