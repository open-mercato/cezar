Drag projects in the navigation to reorder them. Appearance provides Reset order to clear your custom order and restore sorting by the most recently opened project.

## Where to find it

Project sidebar / Settings → Global → Appearance → Project order

## How to use it

1. Drag projects in the sidebar.
2. Open Appearance to undo the custom order.
3. Choose Reset order.

> **Good to know**: Reset appears only when there are multiple projects and a saved manual order. The order is shared between browsers using this instance.
