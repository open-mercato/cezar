Select a folder in the directory browser. Cezar also accepts folders without Git, but runs at most one task at a time in them.

## Where to find it

Add project → Open local folder

## How to use it

1. Browse to the project directory and select the folder.
2. Open the selected folder in Cezar.

> **Good to know**: You can browse only within the configured root directory. Single-project mode prevents you from adding projects.
