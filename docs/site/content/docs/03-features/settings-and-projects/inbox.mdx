Inbox collects follow-up actions and notes left by agents. Turn a suggested action into a new task by choosing an agent and model and adding instructions. Informational notes can be acknowledged and removed.

## Where to find it

Inbox

## How to use it

1. Set `CEZ_FOLLOWUPS=1` and restart Cezar.
2. Open Inbox after a task that left a suggested follow-up.
3. Select an agent and model, optionally use Add instructions, then choose Run. Remove an unwanted item with Dismiss.

> **Good to know**: Inbox is not a manual manager for your own TODO list. Its entries come from a file maintained by agents. Notes for an individual task work independently.
