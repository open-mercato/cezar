The project limit controls how many of its tasks can run together. The global limit on parallel tasks still applies.

## Where to find it

Settings → Global → Projects → Max parallel tasks for the project

## How to use it

1. Open project settings and set the parallel task limit.
2. Check how many tasks are running and how many are waiting in the queue.

> **Good to know**: Raising the project limit does not reserve extra resources or increase the global limit.
