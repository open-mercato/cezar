Machine shows CPU usage, occupied memory, and the time of the last measurement. The local view also includes a short history chart. In a resource-limited container, it shows the capacity actually available to the container.

## Where to find it

Settings → Global → Resources → Machine

## How to use it

1. Open Resources.
2. Check CPU, RAM, and the updated timestamp.
3. Compare the load with the concurrent task limit.

> **Good to know**: The remote cockpit labels measurements last known. It does not present them as a continuous local chart.
