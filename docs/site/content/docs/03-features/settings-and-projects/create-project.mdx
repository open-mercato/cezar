New project creates a local Git repository and registers it in the workspace. With gh signed in, you can also create a private repository in your account or an organization, either empty or based on a GitHub template.

## Where to find it

Add project → New project

## How to use it

1. Enter a project name and check the destination folder.
2. Choose a local project, or Create a private GitHub repository and select its owner.
3. Choose Empty or From a template. For a template, provide owner/repo or a URL.
4. Create the project and start its first task.

> **Good to know**: Templates require GitHub. GitHub repositories are always private when created. If a later step fails, a remote repository that has already been created remains.
