An agent session waiting on CI can move into the monitoring pool, allowing other tasks to keep working.

## Where to find it

Settings → Resources → Extra monitoring sessions

## How to use it

1. Set the number of extra sessions.
2. Run a workflow that reports monitoring activity.
3. Check that other tasks continue running in parallel.

> **Good to know**: When the monitoring pool fills up, sessions waiting for results may still hold up the queue.
