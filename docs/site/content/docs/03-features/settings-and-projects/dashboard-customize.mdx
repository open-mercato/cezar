Customize controls the optional modules in the current dashboard view. Reorder them by dragging or using the keyboard. Settings are shared between browsers using the workspace.

## Where to find it

Dashboard → Customize

## How to use it

1. Turn on the modules you need.
2. Drag a module by its handle to reorder it.
3. Use Reset order to restore the default layout.

> **Good to know**: Some core sections are fixed. The optional modules depend on the selected view.
