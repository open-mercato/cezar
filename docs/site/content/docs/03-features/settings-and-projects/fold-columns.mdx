The information needed to identify each task stays visible when you hide extra columns.

## Where to find it

Tasks → column headers

## How to use it

1. Click the header of an optional column.
2. Click it again to restore the column.

> **Good to know**: Cezar remembers the selection across projects in the shared workspace. In a new workspace, the Branch column starts collapsed.
