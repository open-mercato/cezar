Cleanup commands release resources before the task directory is removed. Set the script order and check variable substitutions. You can follow their execution when deleting worktrees or reclaiming space.

## Where to find it

Project settings → Worktrees → cleanup commands

## How to use it

1. Add a cleanup command.
2. Set the order and check variable substitutions.
3. Save and follow execution when deleting worktrees or reclaiming space.

> **Good to know**: The script runs while the task files still exist. If it fails, Cezar keeps the directory for recovery.
