Use the form to choose a repository and where to save its files.

## Where to find it

Add project → Clone from GitHub

## How to use it

1. Choose a repository and destination folder.
2. Start cloning.
3. Open the added project.

> **Good to know**: The Projects settings or `CEZ_PROJECTS_DIR` determine the default folder.
