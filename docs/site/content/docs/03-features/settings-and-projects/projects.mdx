Projects registered in Cezar can share tags. In All tasks, you can filter by project, tag, status, and workflow.

## Where to find it

All tasks

## How to use it

1. Add a second project.
2. Give related repositories shared tags.
3. Open All tasks and set your filters.

> **Good to know**: All tasks appears after you add a second project and includes registered projects.
