The limit covers the task process and any child processes it starts.

## Where to find it

Settings → Resources → Per-task memory limit

## How to use it

1. Set a memory limit.
2. Watch the running tasks.
3. Return to a paused task when needed.

> **Good to know**: Leave the field empty if you do not want to configure a memory limit for the task.
