Set the color in the appearance settings.

## Where to find it

Settings → Appearance → Accent

## How to use it

1. Open Appearance.
2. Choose an accent color.
3. Check how the buttons look.

> **Good to know**: This changes the color of interface elements. Task statuses stay unchanged.
