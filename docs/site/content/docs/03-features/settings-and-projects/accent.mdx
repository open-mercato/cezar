Cezar uses one accent color, violet, for buttons and other primary actions. It cannot be changed.

## What changed

Earlier versions offered an accent picker under Settings → Appearance → Accent. The November 2026 redesign removed it. A previously saved accent choice is kept in your settings file but has no effect.

> **Good to know**: Task statuses have their own colors, independent of the accent.
