Compact reduces spacing to fit more items on screen. Wide and Narrow control the width of conversation text.

## Where to find it

Settings → Appearance → Density / Reading width

## How to use it

1. Choose Compact to reduce spacing.
2. Choose Wide or Narrow for conversations.

> **Good to know**: Compact keeps the same text size. The Changes view always uses the full available width.
