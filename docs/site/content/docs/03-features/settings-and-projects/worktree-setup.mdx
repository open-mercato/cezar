Setup commands prepare the environment after a worktree is created and before the agent starts. You can set their order and an optional timeout. Preview shows variable substitutions before you save the scripts.

## Where to find it

Project settings → Worktrees → lifecycle scripts

## How to use it

1. Add a setup command.
2. Set the command, order, and optional timeout.
3. Check Preview and choose Save scripts.

> **Good to know**: Scripts run non-interactively in Bash. Preview shows substitutions without executing commands.
