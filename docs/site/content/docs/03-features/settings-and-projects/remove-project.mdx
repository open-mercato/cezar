Remove from workspace removes the project's entry from the workspace.

## Where to find it

Settings → Global → Projects → Remove / project settings

## How to use it

1. Open project settings.
2. Choose Remove from workspace.
3. Confirm the selected project.

> **Good to know**: Unregistering a project does not delete files or task history. It does not return automatically after restart; you can add it again from disk. The startup project and projects with running tasks cannot be removed through this panel.
