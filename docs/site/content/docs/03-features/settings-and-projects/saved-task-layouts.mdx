The Layout menu saves the current set of views and their widths under a name. Saved layouts are available to other tasks. Splitting a view temporarily does not create a new template automatically.

## Where to find it

Task → Layout

## How to use it

1. Arrange the views and adjust their widths.
2. Open Layout and save the current layout with a name.
3. Select the saved layout in another task.

> **Good to know**: Available views depend on the task and host capabilities.
