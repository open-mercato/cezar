A server environment variable enables this mode.

## Where to find it

`CEZ_SINGLE_PROJECT=1`

## How to use it

1. Start Cezar with this flag.
2. Work in the startup project.
3. Remove the flag and restart to restore access to multiple projects.

> **Good to know**: Cezar keeps existing project entries. While this mode is enabled, it blocks adding, editing, checking out, and removing projects.
