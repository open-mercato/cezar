The export menu collects the dashboard modules currently shown. CSV is available for further analysis; the print version uses the browser print dialog.

## Where to find it

Dashboard → Export

## How to use it

1. Set the scope and visible modules.
2. Choose CSV or print/PDF.
3. For PDF, choose to save a file in the print dialog.

> **Good to know**: Export includes the visible modules, not the entire raw workspace history.
