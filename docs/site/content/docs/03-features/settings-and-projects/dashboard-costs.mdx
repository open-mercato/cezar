Usage & cost shows usage recorded in retained tasks. You can compare projects, follow daily trends, and compare backends and models.

## Where to find it

Dashboard → Usage & cost

## How to use it

1. Select a period and a cost or token metric.
2. Open the project breakdown.
3. Check Trends and Backends & models.

> **Good to know**: Costs come from data reported by providers. The view indicates incomplete coverage. It does not replace a full account bill.
