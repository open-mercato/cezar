The worktree list shows linked tasks, directory sizes, and ages. Reclaim now removes directories past the retention limit. After confirming, check the cleanup script results.

## Where to find it

Project settings → Worktrees → Reclaim now

## How to use it

1. Check the tasks, sizes, and directory ages.
2. Use Reclaim now for directories past the retention limit.
3. Confirm and check the cleanup result.

> **Good to know**: Reclaim keeps branches. Delete removes both the directory and its branch.
