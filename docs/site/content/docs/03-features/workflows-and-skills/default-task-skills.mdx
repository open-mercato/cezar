New task skill sets the default instructions for making changes. Ask skill sets them for repository questions. These separate settings let the two task types start with different instructions.

## Where to find it

Project settings → Tasks → Default skills

## How to use it

1. Select New task skill.
2. Select Ask skill.
3. Open a new task form without manually selecting a skill.

> **Good to know**: The default skill is selected only when the user has not chosen another.
