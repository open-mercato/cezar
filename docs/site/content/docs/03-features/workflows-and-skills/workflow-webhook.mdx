The Webhook node sends an HTTP POST request to a supplied HTTP or HTTPS address. Place it after the step that should trigger the message, then connect done and failed. Enable the feature with `CEZ_WORKFLOW_WEBHOOKS=1`.

## Where to find it

`CEZ_WORKFLOW_WEBHOOKS=1` → Workflows → Webhook

## How to use it

1. Start Cezar with `CEZ_WORKFLOW_WEBHOOKS=1`.
2. Add a Webhook node and an HTTP or HTTPS URL.
3. Connect done and failed.

> **Good to know**: Webhooks are disabled by default. With `CEZ_DRY_RUN=1`, Cezar sends no requests.
