The graph shows the saved workflow with current node states, iterations, costs, and transitions. Child task nodes link to their own graphs.

## Where to find it

Task → Graph

## How to use it

1. Run a workflow and open Graph.
2. Select a node to inspect its details.
3. Open the child task if that step created one.

> **Good to know**: This view shows the execution of a saved workflow definition. It does not allow editing the graph.
