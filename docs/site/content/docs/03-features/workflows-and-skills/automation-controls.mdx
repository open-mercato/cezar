Each row has Run now and Pause or Enable. Manually running a scheduled rule does not shift its next scheduled time.

## Where to find it

Automations → selected rule

## How to use it

1. Choose Run now to trigger the rule manually.
2. Open the resulting task from the result or log.
3. Use Pause to stop future automatic runs. When the rule still has queued or running tasks, a dialog lists them first — queued tasks that never started, queued tasks continuing earlier work, and tasks running or waiting — and offers **Pause and cancel queued tasks**.
4. For a paused rule, choose More → Pending tasks… to see and cancel what it left queued.

> **Good to know**: Pause does not cancel a task that is already running. Stop that task through its own actions. Tasks a paused rule launched can no longer dispatch new subtasks; a task you started with Run now can. Enable the rule again to lift that.
