Before running an imported workflow, review its steps and referenced skills.

## Where to find it

Workflows → Import / Export

## How to use it

1. Open Workflows.
2. Export a sequence or import a YAML file.
3. Review the steps before running it.

> **Good to know**: Before running a workflow in another environment, make sure its skills, commands, and agent CLIs are available there.
