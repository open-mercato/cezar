Preview matches shows matches for a saved event rule. It is separate from Run now, which can create tasks.

## Where to find it

Automations → event rule → Preview matches

## How to use it

1. Set and save the GitHub or tracker filters.
2. Choose Preview matches or Preview saved matches.
3. Check the results before enabling the rule.

> **Good to know**: The preview uses saved conditions. Scheduled rules show future run times instead of event matches.
