Assign a template to a skill to avoid pasting the same instructions each time.

## Where to find it

Settings → project → Instructions → Prompt templates → skill assignment

## How to use it

1. Create a template.
2. Assign it to a skill.
3. Select that skill in an empty task form.

> **Good to know**: Automatic filling works only before you enter your own text. Existing instructions are preserved.
