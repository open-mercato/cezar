Fork splits work between two to four agents. Connect their branches to one Join node, which waits for all results or the first success.

## Where to find it

Workflows → Add node → Fork / Join

## How to use it

1. Add Fork and set the number of branches.
2. Connect each branch to an agent, then connect the agents to one Join.
3. In Join, choose whether to wait for all results or the first success.

> **Good to know**: Each agent works in a separate worktree. In any mode, the first success cancels the remaining branches.
