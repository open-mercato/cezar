Sync with base merges the current base branch into the task branch. Connect done to the next step. Connect conflict to an agent and pass the conflict list with \{\{nodes.ID.conflicts\}\}.

## Where to find it

Workflows → Add node → Sync with base

## How to use it

1. Add Sync with base.
2. Connect done to the next step.
3. Connect conflict to a conflict-resolution agent and pass \{\{nodes.ID.conflicts\}\}.

> **Good to know**: If there is a conflict, the merge stays in progress so the agent can resolve it.
