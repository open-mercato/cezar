The editor includes a template palette. Existing automations have a Duplicate menu action. After copying a rule, you can change its task text and conditions.

## Where to find it

Automations → New automation → Start from a template / More → Duplicate

## How to use it

1. Open the template palette and choose Use this.
2. Check the trigger, prompt, and agent.
3. Save your rule and enable it after checking the settings.

> **Good to know**: After copying a rule, check its connections and whether the selected skills are available in the destination project.
