Once adds a date and time in the server time zone. After its single scheduled time is used, the rule is paused and the log explains why.

## Where to find it

Automations → New automation → On a schedule → Once

## How to use it

1. Choose Once and set the date and time.
2. Enter the task and choose its agent.
3. Check the time preview, save, and enable the rule.

> **Good to know**: The CLI accepts a one-time date with --at "YYYY-MM-DD HH:MM". The server must be running, and missed-run catch-up rules apply.
