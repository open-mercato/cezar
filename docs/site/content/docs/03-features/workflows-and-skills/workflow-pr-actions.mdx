GitHub nodes can comment on an issue or PR, set labels, request a review, or mark a PR ready. Fill in the content or recipients for the selected node and connect done and failed.

## Where to find it

Workflows → Add node → PR comment / Update PR / Issue comment

## How to use it

1. Add the GitHub node you need.
2. Enter comment text, labels, or reviewers.
3. Connect done and failed.

> **Good to know**: Issue comment uses the issue linked to the task by default.
