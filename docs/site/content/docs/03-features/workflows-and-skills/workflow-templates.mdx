Templates cover implementation with tests (implement-and-verify), implementation with review and a PR (implement-review-pr), review by several agents (review-council), and CI repair (fix-ci). Select a template, adapt its test commands and prompts, then save your own copy.

## Where to find it

Workflows → built-in templates

## How to use it

1. Choose implement-and-verify, implement-review-pr, review-council, or fix-ci.
2. Adapt test commands and prompts.
3. Save your own copy of the workflow.

> **Good to know**: review-council runs three reviewers and a separate agent that decides the outcome.
