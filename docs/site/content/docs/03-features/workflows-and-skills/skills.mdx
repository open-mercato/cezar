Skills are instructions written in Markdown. Cezar detects local skills and can download your team's shared repository into a global cache.

## Where to find it

Skills

## How to use it

1. Open Skills and read the instructions.
2. Select a skill in a new task or workflow.
3. Refresh the catalog after shared instructions change.

Repo commands installed by tools such as spec-kit (`.claude/commands`, `.codex/prompts`, `.cursor/commands`, `.opencode/command`, and `*.prompt.md` in `.github/prompts`) are listed as project skills too, so `/speckit.specify` autocompletes in the composer. Cezar fills `$ARGUMENTS` with what you type after the command and uses the definition that matches the task's agent when several agents ship the same name. Global `~/.claude/commands` are not included.

When a task runs in its own worktree, Cezar installs every skill it uses into the worktree's `.claude/skills` and `.agents/skills`, where Claude Code, Codex, Cursor and OpenCode look for them, under any agent account. That covers the skill you select, a leading `/name`, a skill the task names in plain text ("run om-auto-review-pr on #12"), and every companion skill those name.

A repository can extend a shared skill with its own `.ai/skills/<name>/SKILL.md` (Open Mercato's repos do this). That extension does not replace the shared skill: Cezar installs the shared skill and tells the agent to apply the extension on top of it. If the shared skill cannot be loaded, Skills shows **Install skills**, the task fetches the team skills before the agent starts, and if it still cannot, the agent is told to stop and ask you to install it instead of guessing.

> **Good to know**: Local skills also work without a network connection.
