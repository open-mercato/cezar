Save a template name and instruction text so you can reuse them in later forms.

## Where to find it

Settings → project → Instructions → Prompt templates

## How to use it

1. Enter a name and instruction text, then save the template.
2. Select the saved template in a supported form.

> **Good to know**: Selecting a template inserts its text into the form. It does not start a workflow.
