Tidy up arranges the nodes in the graph. Save the workflow to keep the new layout.

## Where to find it

Workflows → editor → Tidy up

## How to use it

1. Open the graph.
2. Click Tidy up.
3. Save the workflow to retain the layout.

> **Good to know**: Connections and workflow logic stay unchanged.
