Choose Plan first to have the agent prepare a workflow for review. You can reorder the steps and remove any you do not need before running it.

## Where to find it

New task → Plan first

## How to use it

1. Describe the task and choose Plan first.
2. Review the proposed steps and skills.
3. Edit the plan, approve it, and start the task.

> **Good to know**: Preparing a plan does not start the task. Cezar waits for you to review and approve the proposed steps.
