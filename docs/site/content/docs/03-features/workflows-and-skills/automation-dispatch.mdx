The Dispatch switch lets an automated task create subtasks with cez task create. Beside it, set the maximum number of subtasks and the review child option.

## Where to find it

Automations → editor → Dispatch

## How to use it

1. Enable Dispatch for the rule.
2. Set Max subtasks.
3. Optionally enable Review child and save the rule.

> **Good to know**: The setting is hidden if the server has disabled Dispatch. Subtasks work in their own worktrees and report results to the parent task.
