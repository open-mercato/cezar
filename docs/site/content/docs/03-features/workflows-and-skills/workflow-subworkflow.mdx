Sub-workflow starts a saved workflow as a separate subtask. Select its name and prompt, then connect the next steps to done and failed.

## Where to find it

Workflows → Add node → Sub-workflow

## How to use it

1. Add Sub-workflow.
2. Select the saved workflow name and prompt.
3. Connect done and failed to the next steps.

> **Good to know**: The subtask has its own worktree, and its budget is allocated from the parent task.
