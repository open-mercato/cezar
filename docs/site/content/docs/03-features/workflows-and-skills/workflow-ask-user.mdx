The question node collects a user answer and passes it through the answered output. Refer to it in a later prompt with \{\{nodes.ID.answer\}\}.

## Where to find it

Workflows → Add node → Ask user

## How to use it

1. Add the question and optional answers.
2. Connect answered to the next step.
3. Use \{\{nodes.ID.answer\}\} in the next prompt.

> **Good to know**: You can provide up to six answer options and a response timeout.
