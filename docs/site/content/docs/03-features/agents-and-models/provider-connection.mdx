A provider card distinguishes missing installation, no connection, detected credentials, and failed checks. Connect starts the supported sign-in process; Check again repeats the check.

## Where to find it

Settings → project → Agents → Providers

## How to use it

1. Find the provider and read its status.
2. If it is Not connected, choose Connect and finish signing in.
3. Return to Cezar and choose Check again.

> **Good to know**: If Cezar cannot open a local terminal, it provides a command to run manually. Detected credentials do not guarantee available account quota.
