Set a default agent, choose another for a task, or assign different agents to individual workflow steps.

## Where to find it

Settings → Agents

## How to use it

1. Install the CLI you want to use and sign in.
2. Check that it is available in Settings → Agents.
3. Select the agent in New task or a workflow step.

> **Good to know**: The provider's CLI handles your subscription, sign-in, and usage limits.
