Set a default agent, choose another for a task, or assign different agents to individual workflow steps.

## Choose a provider

Open **Settings → Global → Agents** and expand the agent. Use its subscription row to manage logins or enter a key for an available provider. For a custom endpoint, enter the base URL and key. Cezar fetches its model list and displays the model count. If the connection fails, check the URL and key, then retry.

For an agent with a single active method, select the method that should serve the next task. Agents that support several providers offer models from their connected methods. New task shows which method serves each model. **Manage providers** opens that agent in Settings.

A project can inherit the workspace's default model or choose its own in **Project → Agents**. Provider keys are workspace-wide. Set them from the local cockpit or run `cezar providers` on the host.
