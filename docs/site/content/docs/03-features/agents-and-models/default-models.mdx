Default models lets you select a model for each runner. Auto leaves the choice to the agent. Selecting a specific model saves it as a project setting.

## Where to find it

Settings → project → Agents → Default models

## How to use it

1. Connect the provider.
2. Select a model or auto (default) in its row.
3. Open a new task and check the preselected model.

> **Good to know**: When `modelsLocked` is active, the panel only displays the model from the agent's native settings.
