The Junie runner connects Cezar to the local JetBrains Junie CLI through ACP. Install the CLI, sign in, then select Junie in the task form.

## Where to find it

New task → runner → Junie

## How to use it

1. Install Junie CLI and sign in.
2. Select Junie when creating a task.
3. Start the task and follow the session.

> **Good to know**: Junie support is experimental. The runner automatically approves permissions and does not enforce `allowedTools`.
