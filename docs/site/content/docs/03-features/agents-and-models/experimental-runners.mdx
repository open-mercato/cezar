Depending on its configuration, OpenCode can use open or local models. The README marks both OpenCode and pi as experimental.

## Where to find it

Settings → Agents

## How to use it

1. Install and configure the CLI you want to use.
2. Check that Cezar detects it in Settings → Agents.
3. Select the agent and try it on a small task.

> **Good to know**: Protocol support and behavior may differ between these agents. Test the selected agent on your own tasks.
