Each profile has its own agent configuration directory. This lets you use several signed-in accounts from the same provider.

## Where to find it

Settings → Global → Agent accounts

## How to use it

1. Open Settings → Agent accounts and add an account.
2. Set up a separate profile directory and sign in through the agent's CLI using that directory.
3. Select the account for the project that should use it.

> **Good to know**: Each account has a separate provider configuration directory. Account editing is disabled by default in remote mode. A trusted self-hosted installation can enable it with `CEZ_REMOTE_AGENT_ACCOUNTS=1`.
