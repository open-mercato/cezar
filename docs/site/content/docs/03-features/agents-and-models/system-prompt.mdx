The additional project instructions apply regardless of which agent you choose.

## Where to find it

Settings → project → Instructions → System prompt

## How to use it

1. Enter your project rules and save them.
2. Start a new task to use the saved instructions.

> **Good to know**: The instructions apply to future runs. Saved session history stays unchanged.
