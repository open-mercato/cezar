Choose an agent and configuration scope to find the file you need. The preview shows the file's original contents.

## Where to find it

Settings → Agent config

## How to use it

1. Choose the agent, file, and configuration scope.
2. Read the file contents.
3. Make your change and save it.

> **Good to know**: Cezar needs access to the local machine to save a file. Saving is blocked when local session handoff is unavailable.
