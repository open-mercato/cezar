The card shows the question and available answers when an agent is waiting for a decision.

## Where to find it

Task thread → question card

## How to use it

1. Open the waiting task and read the question and its available options.
2. Send your answer.

> **Good to know**: Question cards are available when the selected agent and execution mode support questions.
