Choose Archive when work is finished to tidy up the task list.

## Where to find it

Tasks → task actions

## How to use it

1. Open the task's actions menu.
2. Choose Archive.

> **Good to know**: Archiving also cancels a pending resume scheduled after a provider's usage limit resets.

> **Good to know**: Archiving a task also archives the finished subtasks it dispatched. Subtasks that are still running, in review or waiting for your answer stay in the task list. Restoring the task brings back the subtasks that were archived with it.
