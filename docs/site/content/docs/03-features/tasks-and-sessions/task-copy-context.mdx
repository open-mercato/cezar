The Copy section in the palette provides the task ID and link, branch name, worktree path, resume command, and PR link when those values exist.

## Where to find it

Task → Task palette → Copy

## How to use it

1. Open the palette and find Copy.
2. Select the information you need.
3. Paste it into a terminal, editor, or message.

> **Good to know**: An action appears only when the task has the corresponding value, such as a branch or PR.
