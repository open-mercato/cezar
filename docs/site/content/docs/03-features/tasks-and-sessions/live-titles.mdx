Rename the task manually if you want its title to stay fixed.

## Where to find it

Settings → project → Tasks → Live title updates

## How to use it

1. Enable Live title updates.
2. Start a task.
3. Rename it manually if you want to keep a fixed title.

> **Good to know**: A manual rename stops automatic title updates for that task.
