You can add details to the request before the agent starts working on it.

## Where to find it

Queued task thread

## How to use it

1. Open a waiting task.
2. Add further instructions.
3. Edit or remove messages before work begins.

> **Good to know**: The agent receives queued messages when the task starts. Adding instructions to a running session is a separate feature.

## Change the queued agent

Choose **Change agent** beside the queued-message hint, select an agent, model,
and reasoning effort, then choose **Save agent**. You can also select another
account when the agent has multiple accounts configured.

The task keeps its ID, instructions, worktree, history, and queue priority.
The scheduler checks the selected account's usage allowance and the normal task
limits before starting it. Switching agents opens a session with the selected
provider; an existing conversation remains in the task history. Native model
locks still apply. Once the task starts, use the normal session controls instead.
