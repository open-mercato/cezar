The Agents panel appears when the session reports subagent activity.

## Where to find it

Task thread → Agents

## How to use it

1. Expand the Agents panel and select an agent.
2. Read its activity and history.

> **Good to know**: The panel shows activity reported by subagents. You cannot use it to launch separate tasks.
