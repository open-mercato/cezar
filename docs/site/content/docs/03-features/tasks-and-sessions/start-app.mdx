Cezar reads saved startup commands, called a recipe, or detects a project command. It runs services in terminals inside the task worktree. When it detects the application address, it opens it in Preview.

## Where to find it

Task → Preview → Start app / Run the app

## How to use it

1. Open an empty Preview.
2. Check the suggested command or recipe and choose Start app.
3. If no address appears automatically, check the terminal or enter it manually.

> **Good to know**: Startup may include installing dependencies. If worktree setup scripts are still running, wait for them to finish.
