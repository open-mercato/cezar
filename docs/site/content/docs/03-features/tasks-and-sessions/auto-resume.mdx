The thread shows the scheduled resume time. When that time arrives, Cezar puts the task back in the normal queue.

## Where to find it

Settings → Resources → Auto-resume after a usage limit

## How to use it

1. Leave the setting enabled.
2. Check the resume time in the thread.
3. Let Cezar add the task back to the queue.

> **Good to know**: Automatic resume requires the provider to report when the limit resets. Cezar attempts to resume 30 seconds after that time, with a maximum of 12 attempts.
