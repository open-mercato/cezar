cez task commands create subtasks, display their list and tree, and return a result in a defined format. A subtask report contains its status and result.

## Where to find it

Agent terminal → cez task

## How to use it

1. In a task context, use cez task create "goal".
2. Check cez task list or cez task tree &lt;id>.
3. Return cez task report --status done --result "result".

> **Good to know**: The commands require a running cockpit and `CEZ_API_URL`. Creation also requires `CEZ_TASK_ID`. Headless `cezar run` does not expose Dispatch.
