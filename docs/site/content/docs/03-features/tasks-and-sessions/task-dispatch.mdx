With Dispatch enabled, an agent can divide work into separate Cezar tasks. Describe the expected result and division of work in your instruction. Created subtasks appear beneath their parent.

## Where to find it

New task → Dispatch

## How to use it

1. Enable Dispatch when creating a task.
2. Describe the expected result and division of work.
3. Follow subtasks beneath the parent task.

> **Good to know**: Dispatch is available by default. `CEZ_DISPATCH=0` disables it on the server. Subtasks have separate sessions and worktrees.
