Click an element in the preview and describe the change you want. Design Mode adds its page address, selector, HTML fragment, styles, and dimensions to your message. If the framework exposes them, the agent also receives the component name and its location in the code. This context is a text description of the page structure (DOM); the feature does not take a screenshot automatically. In selection mode, clicking selects an element without activating its button or opening its link.

## Where to find it

Task → Preview → Design Mode

## How to use it

1. Start the task application and open its local address in Preview.
2. Turn on Design Mode and click an element on the page.
3. Describe the change and send the note to the agent.

> **Good to know**: Design Mode works in the local cockpit for http:// addresses pointing to the same computer (loopback). Selection mode starts turned off. `CEZ_DESIGN_MODE=0` disables the entire feature. It is unavailable in the hosted cockpit.

> **Good to know**: Some apps refuse to be embedded in another page (`X-Frame-Options: SAMEORIGIN` or `frame-ancestors 'self'`, which many Next.js apps send), so Preview shows a blank page even though the app opens fine in a browser tab. Turn on Design Mode: its local copy of the app allows the cockpit, and only the cockpit, to embed it. The app's other security headers are passed through unchanged.
