Each task has its own description and workflow. Queued tasks stay in the queue when you restart Cezar.

![The task list with running and queued tasks](/images/task-view.png)

## Where to find it

New task → Tasks

## How to use it

1. Open New task and describe the result you want.
2. Choose a workflow and start the task. Add more tasks in the same way.
3. Open Tasks to see what is running and where each waiting task sits in the queue.

> **Good to know**: The default global limit allows up to 2 tasks at once. In folders without Git, tasks run one at a time.
