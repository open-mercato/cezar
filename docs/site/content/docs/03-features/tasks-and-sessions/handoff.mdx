Cezar saves the information needed to resume supported sessions. You can also open a session directly in the CLI.

## Where to find it

Task → Continue

## How to use it

1. Open an existing task.
2. Choose Continue to add a message.
3. Use terminal handoff if you want to work directly in the CLI.

> **Good to know**: Opening a local terminal depends on the machine's capabilities and the agent's session support.
