A separate limit would cover active Dispatch subtasks across all parent tasks. Further subtasks would wait in the queue once this limit is reached.

## Status

Specification: not yet available

## What you can do today

1. Apply a shared active-subtask limit in addition to individual parent limits.
2. Queue further subtasks when the workspace reaches that limit.

> **Good to know**: Cezar already has `maxParallel` and a per-parent subtask limit. The current configuration and semaphore lack `dispatchMaxConcurrent` and a separate admission counter. There is no confirmed delivery date.
