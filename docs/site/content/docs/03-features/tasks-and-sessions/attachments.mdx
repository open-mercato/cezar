Add files through the file picker, drag them into the message field, or paste them from the clipboard. Cezar recognizes images, PDF, and text. Other files are sent as binary attachments whose paths are provided to the agent.

## Where to find it

New task or conversation → Attach files

## How to use it

1. Choose Attach files or drag a file into the message field.
2. Explain what the agent should do with it.
3. Remove any unwanted attachment before sending the message.

> **Good to know**: Each file has a 5 MiB limit. Images in one message have a combined 20 MiB limit. How files are read depends on the runner and its available tools.
