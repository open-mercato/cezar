Type / to see matching skills, or @ to search file paths exposed by the current conversation view. Selecting a suggestion inserts it at the cursor.

## Where to find it

Message field → / or @

## How to use it

1. Type / and part of a skill name.
2. Select a suggestion.
3. For a file, type @ and part of its path.

> **Good to know**: The file list depends on the context source for that view. It does not attach the entire repository automatically.
