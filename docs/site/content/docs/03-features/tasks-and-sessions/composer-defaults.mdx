New task defaults sets the initial Autonomous and Use a worktree values. Choose On, Off, or Inherit environment. You can override the choice in an individual task form.

## Where to find it

Settings → Global → Resources → New task defaults

## How to use it

1. Set Autonomous by default.
2. Set Use a worktree by default.
3. Check a new task. You can change the choice for that run.

> **Good to know**: Multistep and parallel runs retain their required isolation. Inherited Autonomous behavior can depend on whether you are starting a skill or a workflow.
