You can cancel a pending resume in the thread. Archiving the task also cancels it.

## Where to find it

Task thread → Don’t resume

## How to use it

1. Open a task waiting for its usage limit to reset.
2. Choose Don’t resume.

> **Good to know**: This cancels only that scheduled resume. The global automatic resume setting stays unchanged.
