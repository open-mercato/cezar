Cancel is available in the task view.

## Where to find it

Task → Stop

## How to use it

1. Open a running or queued task.
2. Choose Stop and confirm.
3. Check the worktree files. Changes made so far remain.

> **Good to know**: Canceling does not undo changes the agent has already made. Check the files in the worktree.
