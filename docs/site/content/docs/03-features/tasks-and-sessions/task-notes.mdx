The Notes tab displays the agent's task handoff file as a Markdown document. Notes have their own page, so longer records can be read outside the conversation.

## Where to find it

Task → Notes

## How to use it

1. Open Notes for the task.
2. Read the work summary and remaining actions.
3. Return to Chat to continue.

> **Good to know**: Content depends on the notes saved by the agent. Task Notes work independently of the optional global Inbox.
