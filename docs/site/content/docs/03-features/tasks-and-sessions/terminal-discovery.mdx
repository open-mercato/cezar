The terminal panel lists project commands and addresses detected in process output. Each address shows its availability and actions to open it in Preview or an external browser.

## Where to find it

Task → Terminal → Commands / Detected addresses

## How to use it

1. Select a project command to run it in a new tab.
2. Find the address under Detected addresses.
3. Click Open Preview or Open in Browser.

> **Good to know**: Detecting a command or address does not run or open it.
