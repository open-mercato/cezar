Task actions let you pin a task, rename it, and mark it as read or unread. These actions are also available in the task palette.

## Where to find it

Task → action menu or Task palette

## How to use it

1. Choose Pin for a task you want to keep nearby.
2. Use Rename to give it a name.
3. Choose Mark unread when you want to revisit the result later.

> **Good to know**: Marking a task unread does not resume the agent.
