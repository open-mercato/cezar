The thread keeps the session history. You can add an instruction or paste a screenshot while the agent is working.

![A task thread showing live agent messages and tool calls](/images/live-run.png)

## Where to find it

Task thread

## How to use it

1. Start a task and open its thread.
2. Expand a tool call to see its result.
3. Send another message if you need to clarify the task.

> **Good to know**: The tools and usage data shown in the thread depend on the agent provider.
