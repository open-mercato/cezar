Cezar saves unsent text and attachments as a draft belonging to the task. It removes the draft after a successful send. If the message is rejected, the draft remains available to edit or send again.

## Where to find it

Task → Chat → message field

## How to use it

1. Start writing a message and add attachments.
2. Switch to another task, then return.
3. Finish the draft and send it.

> **Good to know**: To survive a page refresh, drafts require the host to allow Cezar data to be saved.
