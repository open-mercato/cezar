The explanation beside a task status shows whether it is waiting for a queue slot, an account quota reset, or another session's automatic resume. Waiting for usage limit reset includes the reset time. With automatic resume, the task waits for the session using that account to resume.

## Where to find it

Tasks → waiting task

## How to use it

1. Find the task in the queue.
2. Read the explanation beside its status.
3. For Waiting for usage limit reset, check the displayed time. For automatic resume, wait for the session using that account to resume.

> **Good to know**: The wait can be caused by a task in another project. Increasing concurrency does not clear an account block.
