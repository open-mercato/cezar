The palette contains task actions, Git operations, views, saved layouts, and commands to open things in other applications. Use @ to search tasks, > for commands, or # for files. You can also assign keyboard shortcuts to commands.

## Where to find it

Task → Task palette

## How to use it

1. Open the task palette.
2. Type a command name or use @, >, or #.
3. Run the selected item. Use Shift+Enter to assign a shortcut.

> **Good to know**: Available actions depend on the task state and host capabilities.
