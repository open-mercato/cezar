## Availability

Every feature page shows a badge next to its title when the feature is not available by default:

| Status | Meaning |
| --- | --- |
| Available | Works with no configuration. No badge. |
| Opt-in | Off by default. The page explains the setting or environment variable that enables it. |
| Experimental | Works, but its behavior can change between releases. |
| Planned | Described in a specification in the repository. You cannot use it yet. |

## Planned features

- [Gemini CLI agent](/docs/features/agents-and-models/gemini-runner): The plan adds Gemini CLI through the ACP protocol.
- [Permission modes and tool approval](/docs/features/agents-and-models/permission-modes): The plan adds permission choices and agent approval responses in the cockpit.
- [Choose a Codex provider per task](/docs/features/agents-and-models/codex-provider-choice): The plan adds a provider choice from model_providers in native Codex configuration.
- [A workspace-wide Dispatch subtask limit](/docs/features/tasks-and-sessions/dispatch-workspace-cap): The plan adds a shared Dispatch subtask limit for the workspace.
- [Reduce concurrency under load](/docs/features/setup-and-integrations/adaptive-dispatch): The plan reduces parallel subtasks when CPU or memory is under pressure.
- [React component library](/docs/features/setup-and-integrations/react-components): The specification proposes embedding parts of Cezar in your own React app.

> **Good to know**: Source links on each page point to the commit the description was checked against (audited 2026-10-23). The latest release does not necessarily include every feature on `main`.
