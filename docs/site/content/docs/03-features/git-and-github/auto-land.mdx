Auto-land commits task changes, synchronizes them, runs checks, and pushes them to the base branch. After reviewing Changes, use Commit to &lt;base> or Finish. An Autonomous task can complete this process itself.

## Where to find it

Project settings → Tasks → How changes land

## How to use it

1. Enable auto-land for work in the checkout.
2. Review Changes and send any corrections.
3. Use Commit to &lt;base> or Finish. An Autonomous task may finish landing on its own.

> **Good to know**: The commit includes all checkout changes outside `.ai/cezar/`, including manual edits. Git-tracked configuration cannot grant this permission.
