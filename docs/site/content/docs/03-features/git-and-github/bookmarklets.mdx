Cezar generates these bookmarks, called bookmarklets, for you to save in your browser.

## Where to find it

Settings → Bookmarklets

## How to use it

1. Choose a generated bookmarklet.
2. Save it in your browser.
3. Run it on an issue or pull request page.

> **Good to know**: The Cezar server must be reachable. Follow the instructions supplied with the generated bookmarklet.
