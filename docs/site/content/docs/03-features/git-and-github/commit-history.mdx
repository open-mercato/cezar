The view lists commits and their changes, with a GitHub link when available.

## Where to find it

Git → Commits

## How to use it

1. Open the commit list.
2. Select a commit.
3. Review its changes or open the GitHub link.

> **Good to know**: The list also shows incoming and outgoing commits based on the last fetch. On a phone, the diff uses a unified layout with wrapped lines.
