In Trunk-based mode, tasks work directly in the checkout, the project's working directory. Verified changes go to the base branch. Where tasks work and How changes land define how this happens and which checks are required.

## Where to find it

Project settings → Tasks → Development model

## How to use it

1. Choose Trunk-based.
2. Check Where tasks work and How changes land.
3. Set the checks required before changes are saved.

> **Good to know**: Tasks that write changes run one at a time in the shared checkout. You can still explicitly choose a separate worktree for a task.
