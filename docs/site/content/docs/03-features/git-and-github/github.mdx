The GitHub tab includes filtering and search, activity history, PR diffs, and manual merging after confirmation. You can also create a task from an issue or PR using your own workflow and skills.

![The GitHub view listing repository issues](/images/github-issues.png)

## Where to find it

Project → GitHub

## How to use it

1. Open Issues or Pull requests.
2. Find and open an item.
3. Read the details or use Hand this to the agent.

> **Good to know**: Access depends on gh configuration, the repository, and permissions. Merging requires a separate action and confirmation.
