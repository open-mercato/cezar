Fix errors asks the agent to correct changes with failed CI checks. The interface may first suggest pushing commits, updating the branch, or resolving conflicts. Complete the suggested step, then follow the fix in the agent session.

## Where to find it

Task with a PR → Fix errors

## How to use it

1. Open the task linked to a PR with failed checks.
2. Complete any earlier suggested push, branch update, or conflict resolution.
3. Click Fix errors and follow the correction in the session.

> **Good to know**: The interface offers only the next applicable step. Sending an instruction does not confirm that CI passes after the fix.
