Enter the commands that must pass before changes are pushed to the base branch, such as tests and lint. Cezar runs these checks during auto-land.

## Where to find it

Project settings → Tasks → Required checks

## How to use it

1. Enter project commands, such as tests and lint.
2. Save the settings.
3. Run a task with auto-land and check the results.

> **Good to know**: A failed check blocks the push. The error can return to an open agent session for correction.
