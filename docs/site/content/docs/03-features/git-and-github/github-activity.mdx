Activity collects the discussion and events for an issue or PR. You can read comments and review summaries, expand commit groups, and open individual events on GitHub.

## Where to find it

GitHub → issue / PR → Conversation

## How to use it

1. Open an issue or PR.
2. Go to Activity.
3. Expand a commit group or open an event on GitHub.

> **Good to know**: Comments can be read here, but not edited. If the history is shortened, the view links to the full thread.
