Drag an issue or PR row from the list into the message field. Cezar inserts its context into the text, which you can supplement with instructions before sending.

## Where to find it

GitHub → issue / PR row → message field

## How to use it

1. Grab an item in the list.
2. Drag it into the composer text field.
3. Add your instructions before sending.

> **Good to know**: Dragging inserts text. It does not start a task.
