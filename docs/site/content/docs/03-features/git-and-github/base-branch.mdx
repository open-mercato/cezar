This setting defines the starting point for future tasks in the repository.

## Where to find it

Settings → project → Tasks → Base branch

## How to use it

1. Choose the base branch.
2. Start a new task.
3. Check the diff and the pull request's target branch.

> **Good to know**: The branch must exist in the repository. Changing this setting does not rebase existing work.
