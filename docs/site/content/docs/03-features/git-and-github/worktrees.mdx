Each worktree is a separate directory, so tasks can change files in parallel. When the work is finished, you can remove the directory and keep the branch to recover the changes later.

## Where to find it

Settings → Resources

## How to use it

1. Start a task in a Git repository.
2. Review its changes in the task's Git view.
3. Open Settings → Resources to review completed worktrees and free up disk space.

> **Good to know**: Cezar keeps 10 completed worktrees by default. Set the value to 0 to keep them without a count limit.
