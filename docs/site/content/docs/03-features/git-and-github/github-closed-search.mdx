Search can find closed issues and merged PRs outside the open list. Enter a number or distinctive text. If the current list has no match, remote results appear under Found on GitHub.

## Where to find it

GitHub → Search

## How to use it

1. Enter the issue or PR number, or distinctive text.
2. If the current list has no match, wait for Found on GitHub.
3. Open a result in the details panel.

> **Good to know**: Remote search runs when the text has no local matches. A label filter alone does not trigger it.
