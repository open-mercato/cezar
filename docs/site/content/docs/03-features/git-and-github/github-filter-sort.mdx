Search issues and PRs by number, title, or author. Labels filters the results by selected labels. You can also sort from newest or oldest.

## Where to find it

GitHub → Issues / Pull requests

## How to use it

1. Enter a number or text in Search.
2. Select the labels you need in Labels.
3. Choose newest-first or oldest-first order.

> **Good to know**: When several labels are selected, a result must have all of them. Cezar remembers the sort order.
