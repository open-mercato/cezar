In the PR view, choose an allowed method: Squash and merge, Create a merge commit, or Rebase and merge. After starting the action, confirm the destination branch in the dialog.

## Where to find it

GitHub → PR → Conversation → merge panel

## How to use it

1. Check the PR state and current revision.
2. Select Squash and merge, Create a merge commit, or Rebase and merge from the available options.
3. Click the action and confirm the destination branch in the dialog.

> **Good to know**: The server refreshes the requirements and rejects a merge if the SHA changes. Drafts and conflicts block the action. Any visible option to bypass requirements is still subject to permissions enforced by GitHub.
