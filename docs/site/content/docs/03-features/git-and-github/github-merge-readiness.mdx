The panel below the PR discussion shows required Reviews, Conflicts, and checks. Use Refresh before merging to read their current state.

## Where to find it

GitHub → PR → Conversation → merge panel

## How to use it

1. Open the panel below the PR discussion.
2. Check Reviews, Conflicts, and checks.
3. Use Refresh to read the requirements again.

> **Good to know**: If the token cannot read checks, Cezar shows their state as unknown. It does not treat missing access as absent CI or permission to merge.
