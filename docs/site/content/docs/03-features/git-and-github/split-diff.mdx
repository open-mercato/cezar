You can also enable wrapping for long lines.

## Where to find it

Task → Changes → Diff layout

## How to use it

1. Open a changed file.
2. Switch the comparison layout.
3. Enable line wrapping if needed.

> **Good to know**: Changing the layout affects only the display. It does not change the files.
