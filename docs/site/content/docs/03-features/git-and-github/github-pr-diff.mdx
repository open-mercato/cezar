Open Changes on a pull request to inspect file differences without starting an agent. Filter files narrows the list; Previous and Next move between files.

## Where to find it

GitHub → Pull requests → PR → Changes

## How to use it

1. Open the PR and its Changes tab.
2. Narrow the list with Filter files.
3. Move between files with Previous and Next.

> **Good to know**: The view shows the SHA identifying the revision being inspected. Refresh indicates when it changes. Cezar marks incomplete diffs and files without a patch.
