Save and publish changes through the next Git step suggested for the task.

## Where to find it

Task → Git action in the header

## How to use it

1. Review the task's Changes.
2. Choose the available Commit, Commit and push, or Create PR step.
3. If a commit form appears, check the message and confirm.
4. Check the result in the session and commit history.

> **Good to know**: Cezar usually delegates the step to the agent. The server-side commit form includes all worktree changes (git add -A); it does not select individual files. The available button depends on branch and PR state.
