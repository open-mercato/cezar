Create an agent task from the selected issue or PR. Choose a workflow, skills, agent, and model, then add instructions to the supplied link. After starting, View task opens the new task.

## Where to find it

GitHub → issue / PR → Hand this to the agent

## How to use it

1. Choose the workflow, skills, agent, and model.
2. Add instructions to the supplied issue or PR link.
3. Start the task and open it with View task.

> **Good to know**: Instruction drafts are saved separately for each item. Workflow and skill selections can be reused for subsequent items.
