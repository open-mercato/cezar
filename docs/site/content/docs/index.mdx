Cezar is a local cockpit for coding agents. You describe a task, choose a workflow and an agent such as Claude Code or Codex, and follow the work live: steps, tool calls, tokens, and diffs. Each task runs in its own Git worktree and stops at a result you review. Cezar never merges on its own.

Cezar runs on your machine. It keeps its state in plain files in your repository and your home directory, so there is no account, database, or cloud service to set up.
