# Project Core
- cezar is a local, zero-config orchestrator/cockpit for parallel coding agents. State is plain JSON/NDJSON/Markdown under `.ai/cezar/`; no accounts, database, or cloud dependency.
- Server/CLI map and cross-cutting invariants: `mem:server/core`.
- React cockpit architecture: `mem:frontend/core`.
- Toolchain and runtime pins: `mem:tech_stack`.
- Project-specific implementation conventions: `mem:conventions`.
- Common developer commands: `mem:suggested_commands`.
- Required completion gate: `mem:task_completion`.
- Feature/design history lives in `.ai/specs/`; read the relevant spec before changing a covered feature.
